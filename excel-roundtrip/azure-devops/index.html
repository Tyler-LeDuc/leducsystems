Excel Round-Trip for Azure Boards

Edit Azure Boards work items in Excel without the Office add-in. Excel Round-Trip exports a query or selected backlog items to an .xlsx file in the browser. Edit it in Excel on Windows, Excel for Mac or Excel for the web, upload it back, and review every change before it is applied.

What it does

  • Export from a query or a backlog. Pick a saved query, or use Export to Excel (Round-Trip) on a query, on query results or on selected backlog items. Choose and order the columns.
  • Hierarchy or flat. Title 1, Title 2, Title 3 columns show parents and children. Put a row's title at another level, or under another parent, to move it. Or use one Title column with a Parent ID column.
  • Dropdowns in the sheet for State (per work item type), Priority, picklists, Area Path and Iteration Path.
  • New work items from blank rows. A Work Item Type and a Title are enough. Children of new rows are linked to the new parent.
  • A diff before anything is saved. Field by field: the current value, the new value, and what changed in Azure DevOps since the export.
  • Validation. Allowed values, state changes the process allows, paths that exist, numbers and dates. Then Azure DevOps checks each change without saving it, so rule errors show up front.
  • Apply with progress and a result per row. A failed row does not stop the others. Each update carries the revision it was previewed at, so a work item someone changed meanwhile is not overwritten.
  • Undo. Every import keeps an undo log. Undo puts the old values and parents back and sends created items to the Recycle Bin.

No Office add-in

The classic "Open in Excel" route needs Excel for Windows with the Azure DevOps Office Integration installed. Excel Round-Trip needs neither: the workbook is built and read in your browser, and the file is a standard .xlsx.

Your data stays in Azure DevOps

Work items are read and written through the Azure DevOps REST API, from your browser, with the Work items (read and write) scope. The .xlsx file is created and read in your browser. Undo logs are kept in your organization's extension data storage for your user. Work item data is never sent to LeDuc Systems; with Pro, only the license key is checked with my license server. FAQ

Does uploading a file change anything? No. The upload shows a preview. Nothing is written until you select Apply.

What happens to formatting in Description? Rich text fields are plain text in the sheet. Cells you do not edit are not touched; an edited cell replaces that field's formatting.

Does deleting a row delete the work item? No. Rows removed from the sheet are left as they are.

Can I import any spreadsheet? A sheet with an ID column and field names as headers works too. Without the hidden sheets of an export, changes are compared with the current values.
