How it works

  1. You describe the task

    Email me the steps, written out or as a screen recording, with a sample of the files involved.

  2. I confirm it’s a fit

    I reply in writing to say I can build it, or why I can’t. If it fits, I send an invoice.

  3. I audit the steps

    Before building anything, I cut the steps that only exist because of how the work grew, like typing the same value into two places.

  4. I build the skill

    The clean process becomes a Claude skill, or a Claude project with instructions if that suits the task better.

  5. You get the files

    Within 5 business days of getting your description and sample files, you get the skill files and a short written setup guide. One round of changes is included within 14 days.

Common questions

Do we need a call?

No. Everything happens by email. If something in your description is unclear, I ask in writing.

What do I need?

A Claude Pro or Team plan, a description of the task, and one or more sample files. If your business uses ChatGPT, I can set the workflow up there instead.

What is a Claude skill?

A folder of instructions, and sometimes templates or small scripts, that Claude uses when you start the task, so it follows your process the same way each time.

Is my data safe?

I only see the samples you send me. If you prefer, send dummy data with the same layout as the real thing. I delete your samples after delivery.

What if it doesn’t work?

If I can’t deliver a working skill for your task, I refund you in full.

Can you do more than one?

Yes. Each workflow is $349, or the monthly plan covers up to 3 new workflows a month plus fixes for $790 a month. You can cancel it anytime.
