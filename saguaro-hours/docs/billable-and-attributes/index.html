Billable and attributes

Each worklog can carry a billable flag and values for attributes your admin defines. Saguaro Hours for Jira stores them next to the Jira worklog. Jira itself does not show them.

Where an admin sets them

Jira settings, Apps, Saguaro Hours.

  • Billable default. When on, new worklogs from the panel are ticked billable, and so are worklogs created in the weekly grid.
  • Attributes. Each has a name and a type.
  • List: a select. Enter the options as a comma-separated list.
  • Text: a free text box.
  • Remaining estimate. Adjust automatically, as Jira does (the default), or leave the remaining estimate unchanged when people log, change or delete time in Saguaro Hours. See weekly timesheet.
  • Save settings stores the changes.

Rules

  • Attribute values are checked against the definitions when saved. A list value outside the options is refused.
  • Deleting an attribute definition hides its values. It does not remove them from storage. A data export still contains them.
  • Only the worklog author can set the flag or attributes.
  • A worklog without a stored record counts as not billable in reports.

Where you see them

  • Grid: a green $ in a cell with a billable worklog.
  • Panel: tags on each entry.
  • Reports: group by billable or by any attribute, and they appear in the detail table and exports (reports-and-exports.md).
  • Rates: only billable hours earn revenue, and one attribute (for example Account) can set the billing rate per value. See Cost and revenue in reports and exports.
