See your Tempo data in Saguaro Hours

Choose a Tempo export and this page shows it the way Saguaro Hours shows timesheets: one week per screen, a row per Jira issue, a column per day. The file is read by your browser and never uploaded. Close the page and it is gone.

Get the file from Tempo: Tempo, then Reports, then Logged Time. Pick the dates, then Export, then Download Raw Data, then the CSV icon (not XLS or XLSX). If you are a Jira admin and want everyone's time, first give yourself the Tempo permission "View Worklogs" on all resources; without it Tempo leaves other people's worklogs out of the export.

No Tempo file to hand? Use the sample, which is made up.

What this shows, and what it does not

This is a preview of how your hours look as Saguaro Hours timesheets. It does not connect to Jira, so it cannot check that each row matches a Jira worklog; the real import does that, and refuses rows it cannot match exactly. Columns the preview does not use (work attributes, approval status and the rest) are ignored here and handled by the import.
