What it does

Engraving rules with a live preview

Set the lines, characters per line, allowed characters and UPPERCASE. Shoppers see exactly what will be engraved, with a count on each line. Free.

Required fields on the Free plan

Add to cart waits until the shopper answers. On products with a required field, Buy it now is hidden and quick add buttons send the shopper to the product page.

One-click templates

Engraving text, Gift message, Name + font and Delivery date. A template goes on one product first, so you can preview it before choosing which products get it.

Every common field type

Text, multi-line text, number, date, dropdown, radio buttons, checkbox and checkbox group. Color swatches are on Pro.

Show-when rules (Pro)

Show a field only when another answer matches, like the engraving box only after the shopper ticks "Add engraving".

No theme code edits

Fields come from a theme app embed or block, and the storefront script is about 4 KB. Uninstall and your theme is exactly as it was.

Setup

  1. Install

    Add LeDuc Product Options from the Shopify App Store.

  2. Switch it on in your theme

    On the app’s home page, click Turn on automatic embed and save your theme. Fields appear above Add to cart. For exact placement, use Add block to product page instead.

  3. Pick a template or build a set

    Start from a template, or click Create option set and add your own fields. Then choose the products, collections or tags that get it.

  4. Place a test order

    Each answer shows under the line item in the cart, at checkout and on the order in your Shopify admin.

Common questions

Where do I see what the shopper typed?

On the order in your Shopify admin, under each line item. Answers are saved as line item properties, so they also show in the cart and at checkout.

Does it work with my theme?

It works with Online Store 2.0 themes, including Dawn and the other free Shopify themes. If the fields do not appear on your theme, email me and I will fix it.

Can an option add to the price, like $10 for engraving?

Not yet. Until it can, the usual way is a variant for it, for example an "Engraving: Yes" variant priced $10 higher.

What about the Buy it now button?

Buy it now skips the cart, so the app hides it on products with a required field. You can hide it on other products too, and if it stays visible the app stops it while an answer is invalid.

What happens if I uninstall?

The fields disappear from your store and no theme code is left behind. Past orders keep their answers.

Who supports it?

I do. I built the app, and support emails come straight to me.
