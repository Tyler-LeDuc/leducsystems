How to add a gift message box in Shopify

Shopify gives you one free spot for a message, the cart note. For a message on the product page, or one message per item, you need a line item property. Here are all three ways.

Method 1: the cart note (built in)

Most themes can show a note box in the cart. In Dawn, open Customize, go to Theme settings, then Cart, and tick Enable cart note. Other themes put the setting in the cart page or cart drawer section.

The note appears on the order under Notes. It is one note for the whole order, it sits in the cart where shoppers often miss it, and Dawn labels it "Order special instructions". You can rename that label under Edit default theme content.

Method 2: a gift message on the product page (theme code)

  1. In Customize, open a product page and add a Custom Liquid block to the Product information section, above the Buy buttons.
  2. Paste the code below and save. The message is saved with that item as a line item property, so two gifts in one order can carry two messages.
  3. Add the product to your cart with a message and check the cart line.
{%- assign form_id = 'product-form-' | append: section.id -%}
<p class="gift-message">
  <label for="gift-{{ section.id }}">Gift message (optional)</label>
  <textarea id="gift-{{ section.id }}" name="properties[Gift message]"
    form="{{ form_id }}" maxlength="250" rows="3"></textarea>
</p>

If your theme does not name its product form "product-form-" plus the section id like Dawn does, use the id of the form that posts to /cart/add.

Method 3: LeDuc Product Options (no code)

  1. Install LeDuc Product Options from the Shopify App Store and click Turn on automatic embed on the app’s home page.
  2. Under Start from a template, pick Gift message. It adds an optional multi-line message of up to 250 characters, on one product so you can preview it.
  3. Choose which products get it, for example a Gifts collection or a gift tag.
  4. On Pro, add a "This is a gift" checkbox and a show-when rule so the message box only appears once it is ticked.

Questions

Where do I see the gift message?

A cart note shows under Notes on the order. A product page message shows under its line item, in the cart, at checkout and on the order.

Is the gift message template free?

Yes. It fits the Free plan, which covers 3 option sets of up to 10 fields each.
