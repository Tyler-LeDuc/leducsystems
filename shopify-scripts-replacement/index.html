Shopify Scripts replacement apps

I'm Tyler, and I make Shopify apps. Shopify Scripts stopped running on every store on June 30, 2026. If a Ruby script used to enforce a checkout rule for you, that rule is gone until something replaces it. This page maps each kind of Script to its replacement, and lists the use cases my apps cover.

What changed

  • April 15, 2026: editing and publishing Shopify Scripts stopped.
  • June 30, 2026: all Shopify Scripts stopped running. Shopify's Help Center now says the Script Editor app was retired and scripts no longer run on any store.

The replacement is Shopify Functions: small programs that run inside Shopify's checkout. Stores on any plan can use public App Store apps that contain functions. Only Shopify Plus stores can use custom apps that contain functions, so writing your own is a Plus option.

Why a validation Function is better than the old workaround

A Ruby Script could change prices, reject a discount code, and hide shipping or payment options. It had no way to return an error that stops an order. So checkout rules built on Scripts were indirect: hide every shipping rate and let checkout fail, or rely on the theme's quantity box.

A cart and checkout validation Function returns an error message, and Shopify's checkout won't place the order until the shopper fixes the problem. The message can sit next to the field that broke the rule. Because it runs in checkout and not in the theme, Buy it now, express checkout buttons and edited carts get the same check.

FAQ

Do Shopify Scripts still run?
No. Editing and publishing Scripts stopped on April 15, 2026, and all Scripts stopped running on June 30, 2026.
What replaces Shopify Scripts?
Shopify Functions. Discount Functions replace line item scripts, Delivery Customization replaces shipping scripts, Payment Customization replaces payment scripts, and Cart and Checkout Validation covers checkout rules such as quantity limits and address blocking.
Do I need Shopify Plus to use Functions?
Not for public apps. Stores on any plan can use App Store apps that contain functions. Custom apps that contain functions need Shopify Plus.
Are your apps available now?
Not yet. They are in Shopify App Store review. Each app's page will link to its listing once it is approved.
