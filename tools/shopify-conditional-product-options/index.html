How to show conditional product options in Shopify

A shopper who doesn't want engraving shouldn't see an engraving box. Conditional options show a field only when an earlier answer calls for it, which keeps the product page short and the orders clean.

Common examples

  • A checkbox "Add engraving" that reveals a text box for the wording.
  • A dropdown "Number of names: 1 or 2" that shows a second name field only for 2.
  • A radio choice "Gift?" that reveals a gift message box.
  • A "Custom color" choice that shows a color swatch or a text field.

Can Shopify do it without an app?

Not out of the box. Shopify's product form shows every variant option all the time. You can hide and show line item property fields with your own JavaScript in the theme, but you have to maintain it through theme updates, and a hidden required field can block Add to cart if the script is wrong.

Plan the rules first

  1. Write each rule as "show this field when that field is this answer".
  2. Keep it to one level where you can. A field that depends on a field that depends on another field confuses shoppers.
  3. Decide what happens to an answer when the shopper changes their mind. A hidden field should not send its old answer with the order.

Test it like a shopper

  • Pick the trigger answer, fill the field, then un-pick the trigger. The field should hide and its answer shouldn't reach the cart.
  • Make the revealed field required and check that Add to cart only waits for it when it's showing.
  • Place a test order and read the order in your admin.
