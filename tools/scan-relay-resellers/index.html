Scan Relay for copier dealers and IT providers

At the end of December 2026, Microsoft 365 stops accepting username-and-password email from copiers. Every client whose MFP sends scans through smtp.office365.com will call you in January. Scan Relay fixes it in about five minutes per office, and you can buy it wholesale.

Try Scan Relay free first Free 14-day trial on any office PC.

What it does

Scan Relay is a small Windows service you install on any always-on PC at the client's office. The copier sends scan-to-email the way it always has, to that PC on port 25, 587 or 2525, with any username and password. Scan Relay sends each scan on to Microsoft 365 with Microsoft's modern sign-in (OAuth, through Microsoft Graph). No firmware update, no static IP, no connector, no DNS changes.

  • Works with any copier or scanner that can scan to email over SMTP.
  • Signs in once with the mailbox scans should come from; the copier never holds a Microsoft password again.
  • Queues scans on disk if the internet drops, and sends them when it's back.
  • Large scans go through Microsoft's upload sessions instead of being rejected for size.
  • Accepts mail only from the office's local network.

Setting up a client

  1. On an office PC that stays on, download and run Scan Relay. It installs itself as a Windows service and opens its setup page.
  2. Sign in with the Microsoft 365 mailbox scans should come from. The first time at each company, a Microsoft 365 admin approves it once ("Consent on behalf of your organization").
  3. On the copier, set the SMTP server to that PC's address (shown on the setup page), port 25, any username and password, no SSL.
  4. Send a test scan, then enter one of your license keys on the setup page.

Questions dealers ask

  • Why not just enable OAuth on the copier? Do that wherever the model supports it. Scan Relay is for the many units that can't, or whose firmware update isn't worth the visit.
  • Why not a Microsoft 365 connector or direct send? Connectors need a static public IP and admin work; direct send only reaches the client's own mailboxes. Scan Relay delivers anywhere, from a normal office connection.
  • Is client data sent to you? No. Scans go from the office PC straight to Microsoft 365. Scan Relay only contacts my server to check a license key.
  • Windows warns that the app is unrecognised. It's new; click More info, then Run anyway.
