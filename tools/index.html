Tools

Small tools for annoying file problems: open files from software you no longer have.

  • Publisher file converterOpen Microsoft Publisher .pub files in PowerPoint, Canva, Affinity or InDesign as editable files. Free preview.
  • Bulk Publisher converterConvert a whole folder of .pub and PageMaker files at once: upload a zip, get PDFs plus editable files back.
  • PageMaker file converterOpen Adobe PageMaker .pmd and .p65 files in InDesign, Affinity, PowerPoint or Canva as editable files. Free preview.
  • PowerPoint text wrapWrap text around pictures in a PowerPoint file, which PowerPoint can't do itself. Free before-and-after preview.
  • Rhino file converterOpen Rhino 8 and 7 .3dm files in older versions of Rhino. Runs in your browser, no upload.
