Converting a Publisher file to Word

Word can't open .pub files, and it was never built for page layouts. Here's how to get the text into Word when that's what you need, and what to do when it isn't.

If you still have Publisher

Publisher can save a copy as PDF (File > Export > Create PDF). Open that PDF in Word with File > Open, and Word converts it into an editable document. For a letter, a report or a list, the result is usable.

If you don't have Publisher anymore

You need something else to open the .pub file first. LibreOffice Draw (free) opens most .pub files and can export a PDF, which Word can then open the same way. Expect fonts to change if you don't have the originals installed.

Why the layout breaks

Publisher places things on a page: a text box here, a picture there, three columns that continue on page 4. Word thinks in a single stream of text that flows from top to bottom. When Word converts a designed page, it either turns everything into floating boxes that jump around as soon as you type, or it pours the text into one long column and drops the design.

That's fine for a document that was mostly text to begin with. It isn't fine for a flyer, newsletter, brochure, menu or card.

What to use for designed pages

Pick an app that works the way Publisher did, with boxes on a page:

  • PowerPoint, which you likely already have. One slide per page, sized to your page, every text box and picture where it was.
  • Canva, which imports PowerPoint files as editable designs.
  • Affinity (free) or InDesign, full layout apps that keep text flowing between linked columns.
