    Questions

    Why won't Rhino 5 open my file?

    Each Rhino release writes a newer .3dm format. Older versions can't read files saved by newer ones, so a file saved in Rhino 7 shows an error in Rhino 5. Normally the only fix is asking the sender to re-save it with "Save As" and an older version, which needs a copy of Rhino 7.

    Is my file uploaded anywhere?

    No. The converter runs entirely in your browser using McNeel's open-source openNURBS library compiled to WebAssembly. Your model is never sent to a server, so it's safe for client work and NDA projects.

    Does it work on Mac?

    Yes. It works in any modern browser on Mac, Windows, Linux and even iPad. Nothing to install.

    What gets converted?

    Geometry, layers, materials, blocks, groups, named views, text and dimensions, user strings and embedded textures. Every converted file is read back and checked before you download it.

    Is anything lost?

    Features that don't exist in Rhino 5 can't be kept. SubD objects need Rhino 7 or newer, and Rhino 4 has no extrusion objects, so those are saved as polysurfaces.
