Convert a whole folder of Publisher files at once

Years of bulletins, newsletters and flyers? Zip the folder and upload it once. Every .pub and PageMaker file comes back as a PDF, an editable PowerPoint file, a Word file and an IDML file for Affinity or InDesign, in the same folders.

Questions

How do I make a zip?

On Windows, right-click the folder and choose Send to > Compressed (zipped) folder. On a Mac, right-click it and choose Compress. Subfolders are fine; the converted zip keeps the same folders.

What do I get?

One zip with every file converted four ways: a PDF to read, print or archive; a PowerPoint file (.pptx) you can edit in PowerPoint, Canva, Google Slides or Keynote; a Word file (.docx); and an IDML file you can edit in Affinity (free) or InDesign.

Which files are included?

Every Microsoft Publisher file (.pub, Publisher 98 and later) and Adobe PageMaker 6 and 7 file (.pmd, .p65, .pm6) in the zip. Other files are ignored and not charged for.

How long does it take?

About 5 seconds per file. 100 files take around 10 minutes, 1,000 files a couple of hours. You can close the page and come back to its address; the zip stays available for 7 days.

What if some files don't convert?

Damaged, password-protected and very old files (Publisher 95 and earlier) are listed in a NOT CONVERTED.txt file inside the zip. If many fail, or the results aren't usable, email tyler@leducsystems.com within 30 days for a full refund.

Can I try it first?

Yes. Drop any single file on the Publisher converter for a free preview of every page, so you can see the quality before you pay for a whole folder. The single-file PDF is $4.99 if you want one.

What happens to my files?

They are converted on my server, used only to make your download, and deleted automatically: within a day if you skip paying, within 7 days if you pay. I never look at them or share them.
