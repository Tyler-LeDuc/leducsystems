Questions

Which files open?

Microsoft Project .mpp files saved by Project 98 through Project 2021 and later (the MPP8, MPP9, MPP12 and MPP14 formats), older .mpx files, and Project XML (.xml) files saved by Project or by other planning tools. Templates (.mpt) are not supported yet.

Is it really free to view?

Yes. The Gantt chart, the task table and the resource list are free for any number of files. Only the exports cost money: $19 once unlocks Excel, CSV and PDF downloads for every project you open.

What happens to my file?

It is sent over an encrypted connection to my server, read there by a program, and deleted as soon as it has been read, before the plan is shown to you. Nothing is stored and I do not open it. The license key is the only thing kept, in your own browser.

Does it work on a Mac?

Yes. Microsoft Project has no Mac version, which is why most people end up here. It works in Safari, Chrome, Edge and Firefox on Mac, Windows, Linux, Chromebook and iPad.

Can I edit the plan?

No. This is a viewer: it shows the plan as it was saved and exports it. To keep editing, open the Excel export, or import the file into a planning tool that reads .mpp.

What is in the Excel export?

Three sheets. Tasks has ID, WBS, name (indented, with outline grouping you can collapse), duration, start, finish, percent complete, predecessors, resources, milestone and critical flags, baseline dates and notes. Resources and Assignments list who does what, with units and work.

What if my file does not open?

Password-protected files can't be read; save a copy without the password in Project first. If a file without a password fails, email tyler@leducsystems.com and I'll look at it. If an export doesn't work for your file within 30 days of buying, I refund you in full.

Is this made by Microsoft?

No. I'm an independent developer. Microsoft Project is a trademark of Microsoft, and this viewer isn't affiliated with Microsoft.
