Where held mail waits

In new Outlook and Outlook on the web, a held message waits in Drafts until it sends. Open it there to edit, or choose No delay and press Send to send it now. Exchange sends it on time even when Outlook is closed, usually within a minute or two of the set time.

The automatic hold on every Send runs when a Microsoft 365 admin deploys Send Delay for the organization. Without that, use Delay this message on the message ribbon.
