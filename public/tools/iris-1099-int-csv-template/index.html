The IRIS 1099-INT CSV template, column by column

The IRIS Taxpayer Portal lets you upload 1099-INT forms (interest income) as a CSV file instead of typing them in one by one. Here are all 66 columns of the template in order, and how the amounts in a FIRE (Publication 1220) file map onto them.

Where the template comes from

Sign in to the IRIS Taxpayer Portal, choose to upload a CSV with form data, and download the blank 1099-INT template. IRIS checks the header row of your upload against that template, so keep the header exactly as it is: same columns, same order, same wording. The column names below are the ones in the IRS's published formatting guidelines for IRIS CSV files.

Use one file per form type and per payer, and keep each file to 100 forms or fewer.

Publication 1220 amount codes to 1099-INT boxes

In a FIRE file, each payee (B) record holds up to 18 payment amounts, numbered 1–9 and A–J. Which box each one belongs to depends on the form, and the codes don't always line up with box numbers.

Formatting that trips people up

  • Amounts are dollars, not cents. A FIRE file stores $1,500.00 as 000000150000. In the CSV it's 1500 or 1500.00.
  • Leave unused amounts blank. An empty cell, not a zero.
  • Names are split. FIRE has one name line; IRIS wants first, middle, last and suffix for people, or a business name line for companies. The FIRE name control (the first four letters of the last name) tells you where the surname starts.
  • Address lines are 35 characters at most. Longer FIRE address lines have to be split between Address Line 1 and Line 2.
  • TIN type has to be stated. SSN, ITIN, ATIN or EIN, which FIRE only partly records.
  • Corrections don't go in this template. Corrected (G or C) records are made in the IRIS portal itself.

Doing it by hand, or not

For a handful of forms, typing them straight into the IRIS portal is quickest. For more, you can fill this template in a spreadsheet using the tables above. If your accounting software only exports a Publication 1220 file, my FIRE to IRIS converter does the mapping, name splitting and file splitting for you, in your browser, so the SSNs in the file are never uploaded.
