Questions

Which files open?

Outlook data files (.pst) from Outlook 97 through Outlook for Microsoft 365, in both the old ANSI format and the Unicode format used since Outlook 2003, and Outlook offline files (.ost), including the newer format Outlook 2013 and later write. Archives, exported mailboxes and "Outlook Data File" backups all open. It does not open Outlook for Mac .olm archives.

Is my mailbox uploaded?

No. The page reads the file on your own computer, a piece at a time, and nothing is sent to my server or anyone else. The only thing that goes to my server is the license check when you save, which sends your license key and nothing about your mail.

How big a file can it open?

Large ones. The viewer never loads the whole file: it reads the folder list first, then only the messages you open, so a mailbox of several gigabytes opens about as fast as a small one. I tested it with a 5 GB mailbox of 60,000 messages: the folders show at once, and a folder of 25,000 messages lists in one to three seconds. Searching all folders and exporting a whole mailbox read more of the file and take longer on big mailboxes.

What is free?

Reading is free, for any number of mailboxes: the folder tree, the message list with search and sorting, every message with its pictures, and every attachment, which you can download one at a time. Only saving costs money: $29 once unlocks saving messages as .eml files (a folder or the whole mailbox in one .zip), as PDF, a folder's attachments in one .zip, and the message list as a CSV spreadsheet, or $9 for 24 hours. The license is a one-time payment, no subscription. Downloads keep working for as long as I run this service, and for at least 2 years from your purchase; if I ever shut it down, I'll email you 90 days' notice.

What does the search find?

It matches the subject, the sender and the recipients, in the open folder or, with "All folders" ticked, across the whole mailbox. It does not search inside the message text.

What is an .eml file and what opens it?

An .eml file is one email in the standard internet format. Apple Mail, Thunderbird and Outlook open it with a double-click, and most mail programs can import a folder of them. Each .eml has the message, its pictures and its attachments, and the .zip keeps the mailbox's folder structure.

What does the PDF look like?

Letter pages with a header block (subject, from, to, cc, date and the names of the attachments) and then the message as it looks on screen, with the pictures that are inside the email. Each page is a picture of the email at print quality, so the text in the PDF can't be selected or searched. Before paying you can download page 1 free, marked as a sample.

Does it open password-protected .pst files?

No. If the mailbox has an Outlook password, the viewer says so and stops. If it is your file, remove the password in Outlook (File, Account Settings, Data Files, Settings, Change Password) and open it again.

Is it safe to open old mail here?

Each message is shown in a sandboxed frame with scripts turned off, so nothing in an email can run. Pictures that emails load from the internet are blocked until you click "Show them", so senders can't tell you opened them. Attachments are saved as they are: if you don't trust the sender, scan them before you open them.

Does it work on a Mac or Chromebook?

Yes. It runs in Safari, Chrome, Edge and Firefox on Mac, Windows, Linux and ChromeOS. On Windows and ChromeOS you can install it from Chrome or Edge, and .pst files then open in it with a double-click.
