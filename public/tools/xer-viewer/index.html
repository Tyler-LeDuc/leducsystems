Questions

Which files open?

XER files exported from Primavera P6 (File, Export, then the XER format). One file can hold several projects; the viewer lists them and you pick which one to look at. If your file does not open, email tyler@leducsystems.com with the error and I will look at it.

Is my file uploaded?

No. The .xer file is read by the page in your browser and never sent to my server or anyone else. The only thing that goes to my server is the license check when you export, which sends your license key and nothing about your schedule.

Is it really free to view?

Yes. The WBS, the Gantt chart, the activity table and the resource list are free for any number of files. Only the exports cost money: $19 once unlocks Excel, CSV and PDF downloads for every schedule you open, or $7 for 24 hours.

What does the viewer show?

The project's name, data date, start and finish; the WBS as a tree you can expand and collapse; and for each activity its ID, name, original and remaining duration, start and finish, early and late dates, total float, percent complete, status, predecessors (type and lag) and resources. Durations, lags and float are shown in days, using the hours per day of each activity's calendar.

How is the critical path shown?

Activities with total float of zero or less are marked critical and drawn in red. That is P6's default definition. If your project defines critical activities by longest path instead, P6 can mark a slightly different set; the float values themselves are exactly what the file holds.

What is in the Excel export?

Four sheets. Activities has the WBS bands and every activity, indented with outline grouping you can collapse, with type, status, durations, all the dates (as real Excel dates), total float, percent complete, critical flag, predecessors and resources. Relationships lists every link with its type and lag. Resources and Assignments list who is on what, with budgeted, actual and remaining units. Before paying, you can download the first 20 activities as a free sample.

Does it recalculate the schedule?

No. It shows the dates and float as P6 last calculated them, as of the data date in the file. If someone changed the logic after the last schedule run in P6, the dates will not reflect it until they schedule (F9) and export again.

What is not shown?

Costs, activity codes, user-defined fields, notebooks, steps, baselines stored in other projects, and resource curves. If you need one of those in the export, email me.

How big a file can it open?

It has been built for large schedules: the file is read in the background, and the table draws 400 rows at a time with a button for more, so a schedule with tens of thousands of activities stays usable (I test it with 20,000). The limit is your computer's memory.

Does it work on a Mac?

Yes. Primavera P6 Professional runs only on Windows, which is why many people end up here. The viewer works in Safari, Chrome, Edge and Firefox on Mac, Windows, Linux and Chromebook.
