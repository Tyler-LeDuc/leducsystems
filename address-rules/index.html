LeDuc Address Rules

Stop orders to shipping addresses you can't ship to. Shopify's checkout shows your message next to the field and won't take the order until the address is fixed.

LeDuc Address Rules is coming to the Shopify App Store; this page will link to its listing once it is approved.

Set up in two minutes

  1. Install the app and open it. PO boxes are blocked from the first visit.
  2. Turn on the other rules you need, edit the messages shoppers see, and click Save.
  3. Type an address under Test an address to see what checkout would say.
  4. Go to your checkout and enter a blocked address, such as PO Box 123. The message shows at the Address field.

What it can block

  • PO boxes: PO Box, P.O. Box, Post Office Box, POB, Box 123 at the start of a line, PO Drawer, Locked Bag, and Postfach, Boîte Postale, Apartado, Casilla and Caixa Postal. Checked in both address lines and the company.
  • APO, FPO and DPO: military city names, the AA, AE and AP armed forces states, and PSC or CMR numbers.
  • Package forwarders: addresses that name well-known forwarding services, such as MyUS, Shipito, Planet Express and Stackry, plus any warehouse addresses you add.
  • Countries: ship only to a list, or block a list.
  • States and provinces: for example Hawaii and Alaska, or Canada's territories.
  • ZIP and postal codes: single codes, prefixes like 100* and ranges like 96700-96899. Block them, or allow only them for local delivery.
  • Your own words: any word or address you never want to ship to.
  • Tagged products only: apply the rules only when the cart has a product with a tag (for example hazmat), or skip them when every product has a tag.

FAQ

Does it work on my theme and plan?
Yes. The rules run inside Shopify's checkout as a checkout validation, not in the theme, so the theme doesn't matter. Express checkout buttons and edited carts go through the same checkout and get the same check.
Where does the shopper see the message?
Next to the field that broke the rule: the Address field for a PO box, the ZIP field for a blocked code, the State field for a blocked state, the City field for APO and FPO. The order can't be placed until the address is fixed.
What about local pickup?
Local pickup and pickup points are never blocked, because nothing ships to the shopper's address. The cart page is never blocked either; the check happens in checkout, where the address is entered.
Will it block streets like "Box Canyon Road"?
No. "Box" only counts at the start of a line followed by a number, like Box 450. Words must match whole, so "Boxwood Lane" and "Po Valley Drive" pass. Try any address in the app's tester before you save.
Can it catch every package forwarder?
No app can. Many forwarder addresses look like ordinary street addresses. The app catches addresses that name a known forwarder, and you can add the warehouse street addresses you see on your own orders.
Which features are on the free plan?
Blocking PO boxes, with your own message. The other rules are on the paid plan.
Didn't Shopify have an address blocker?
Shopify's Checkout Blocks app had one; Shopify deprecated it and set it to sunset on August 31, 2026.
Does it store customer data?
No. Shopify passes the shipping address to the app's checkout function inside Shopify, which answers allowed or blocked. Addresses are never sent to or kept on the app's server. See the privacy policy.
What does it need access to?
One permission: write checkout validations, to register the rule. Your rules are stored on that validation in your own store.
